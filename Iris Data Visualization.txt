# Iris Data Visualization

## Problem Statement

Visualize patterns and relationships in the Iris Dataset using different charts.

## Dataset Used

Iris Dataset (loaded from Scikit-Learn)

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn
* Google Colab

## Tasks Performed

* Loaded Iris Dataset
* Created Bar Chart for species distribution
* Created Histogram for Sepal Length
* Created Scatter Plot for Sepal Length vs Petal Length
* Generated descriptive statistics

## Results

* Visualized species distribution
* Analyzed sepal length distribution
* Observed relationship between sepal length and petal length
* Generated summary statistics of all features

* task2_iris_data_visualization.ipynb
